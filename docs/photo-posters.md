# 照片纸海报使用指南

这两个 Skill 都以用户提供的照片为起点，制作平面纸海报。共同目标是主体清晰、构图与色彩协调，并保留来源照片独有的场景特征；主要区别是最终画面是否继续以真实摄影为主体。

安装方法见[项目 README](../README.md)。两者是独立 Skill，选择需要的一个即可，无需先后执行。

## 如何选择

| 选择依据 | `scene-distillation-zine`：影像蒸馏 | `scenes-gathered-zine`：实景拼贴 |
|---|---|---|
| 最终画面 | 全部重新创作为插画、纸张与文字，不保留摄影像素 | 保留清晰连贯的摄影主体，以插画、纸面与拼贴改善构图 |
| 适合需求 | 希望把照片重新诠释成独立插画作品 | 希望保留人物、物件或场景的摄影真实感 |
| 来源保留方式 | 保留主体、关系、光线或情绪等有辨识度的线索，再重新组织画面 | 保护主体身份、形态、透视、自然色彩与关键场景关系 |
| 可提出的风格要求 | 默认克制重构，可明确要求更强抽象；支持“单色块模式” | 默认克制拼贴，可要求杂志／编辑版式；强拼贴需明确提出 |
| 默认文字交付 | 图片、简短中文创作想法与艺术指导 | 图片及简短中文创作思路，详细说明按需提供 |
| 执行规则 | [影像蒸馏 SKILL.md](../scene-distillation-zine/SKILL.md) | [实景拼贴 SKILL.md](../scenes-gathered-zine/SKILL.md) |

影像蒸馏不是照片滤镜或照片片段拼贴；实景拼贴也不应把定义主体重画成插画。若保留摄影真实感是首要条件，选择实景拼贴。

## 准备照片与环境

- 在对话中附上原照片，并说明想使用哪个 Skill；缺少必要照片时会要求补充。
- 运行环境需要可用的图像生成能力；复制 Skill 文件本身不会提供图像生成服务。
- 可同时说明希望保留的主体、横竖方向、画幅比例、指定文字及风格。无需自行编写完整生成提示词。
- 两者默认直接生成图片；只要提示词时需明确提出。若需要把图片保存到指定项目路径，也请说明位置。

## 调用与风格示例

全插画重创作：

```text
使用 $scene-distillation-zine，把附图转为插画风纸海报。
保留主体的姿态和原图光线，画面清晰、色彩协调，保持原图的横竖方向。
```

影像蒸馏的“单色块模式”使用纸色、中性墨色和一块连续、不拆分的饱和色域；它不是把整张图片处理成单色照片。需要时使用准确触发词：

```text
使用 $scene-distillation-zine 处理附图，使用单色块模式，不添加文字。
```

保留真实摄影主体：

```text
使用 $scenes-gathered-zine，把附图做成纸海报。
保留人物表情、自然肤色和真实光线，用克制拼贴与留白改善构图。
```

希望更明显的编辑排版时，可说“使用 $scenes-gathered-zine，做成杂志感编辑版式，留白更充分”；只有明确要求“强拼贴”“实验性”或“强抽象”等处理，才启用强拼贴模式。强拼贴仍需保留可识别的摄影主体及关键事实，不等于改用影像蒸馏。

## 画幅、留白与输出

两者默认延续原照片的横竖方向。影像蒸馏默认竖图采用 3:5、横图采用 5:3，可另提比例；实景拼贴不会默认把所有照片改成竖版，只有用户要求或来源构图适合时才使用 3:5 竖版。

实景拼贴在普通情况下以至少约 25% 的安静纸面作为设计检查基线；编辑模式会增加留白。用户要求满版，或人群、森林、城市密度等来源特征会被强行留白破坏时，可以减少留白。这是构图规则，不是精确像素验收承诺。

默认不添加文字。需要标题或其他字句时，请给出准确内容；文字应服从主体与整体画面。交付以生成图像为主，简短说明帮助理解创作选择，默认不会披露完整生成提示词。

## 使用限制与进一步阅读

两者都围绕所附照片进行创作，不默认另找图片或把源照片存入项目。结果是生成图像，主体、细节及文字表现仍需查看成图确认；有必须保留的细节，请在请求中明确指出。

这些 Skill 面向纸海报创作，不包含印厂交付、出血或印刷色彩管理流程。实景拼贴的进阶排版、材料与定向修正规则见[艺术指导参考](../scenes-gathered-zine/references/art-direction.md)，一般使用无需阅读该内部参考。
