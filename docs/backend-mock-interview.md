# 后端模拟面试使用指南

[返回项目首页](../README.md) · [Skill 执行入口](../backend-mock-interview/SKILL.md)

## 适合什么场景

`backend-mock-interview` 面向初级、中级和高级后端岗位，模拟一名有经验的技术面试官，不限定 Java 技术栈。**招聘要求确定考察目标，简历和经历确定重点，自我介绍确定切入点，现场回答决定后续追问。**

面试可包含项目深挖、技术基础、场景式故障排查、系统设计，以及必要的编码、SQL 或代码分析，具体内容随岗位和回答调整。每轮只问一个主要问题并等待回答，已经明确的信息不重复询问。

它适用于完整或有重点的模拟面试；仅需题库、技术答疑或简历润色时，无需使用此 Skill。面试过程中不会在每题后立即讲解标准答案或逐题打分，技术纠错与改进建议集中在结束后的复盘中。

## 开始前可以提供什么

按已有材料提供即可，不需要填写完整表单，也没有资料齐全才能开始的限制。

- **JD 或目标岗位**：用于确定岗位要求与评价基准；没有 JD 时，可以说明希望练习的方向和级别。
- **简历、工作与项目经历**：用于选择重点，核对个人职责、技术决策和成果依据。
- **项目 README、架构文档、指定模块或数据库脚本**：用于从真实实现切入；提供本地项目时，说明实际路径和希望考察的范围。
- **本场偏好**：例如预计时长、多问数据库、不问算法或只按 JD 面试，直接用自然语言说明。

只有 JD、只有简历或完全没有材料都能开始。没有资料时，会先通过自我介绍了解最近的工作、项目和目标方向；提供项目时，按需查看相关入口和实现。

预计时长用于安排节奏，Skill 不自带计时器，不保证自动到点结束；希望收尾时可以直接提出。项目指标可以脱敏或使用近似范围，缺失的信息不会被补成事实。

## 三种启动方式

先按[项目首页的安装说明](../README.md)安装，再在对话中调用。

### 直接开始

```text
使用 $backend-mock-interview 开始一场后端模拟面试。
```

### 结合 JD 和简历

```text
使用 $backend-mock-interview 对我进行一场后端技术模拟面试。
附件中包含目标岗位 JD 和我的简历。预计 60 分钟，不问算法，重点考察项目设计与线上排障。
```

### 结合本地项目

将示例路径替换为你实际提供的项目路径：

```text
使用 $backend-mock-interview，结合 E:\projects\order-service 中的 README、订单模块和数据库脚本进行面试。
目标岗位是 3～5 年 Java 后端，重点考察项目设计、MySQL、Redis 和线上排障。
```

## 面试过程中如何调整

默认以 JD 为岗位基线；回答扎实时，会选择一至两个相关领域增加规模、并发、故障或架构约束，探索本场已展示的能力边界。进阶题未答出不会直接推翻已验证的岗位基础，也不代表已经确定候选人的绝对能力上限。

| 可以直接说 | 对应行为 |
| --- | --- |
| “继续” | 接回当前面试，不重复已答问题 |
| “下一题”“跳过”“换一个” | 停止当前追问并转场；跳过不等同于不会 |
| “不会” | 记录当前问题的边界，可能简化一次或转场，不立即讲答案 |
| “简单一点”“难一点”“只按 JD 面试” | 调整复杂度或进阶探查范围 |
| “多问项目”“多问数据库”“不问算法” | 调整重点或遵守排除要求，未覆盖的岗位能力会在复盘中说明 |
| “暂停” | 暂停提问，等待继续，不自动结束或复盘 |
| “结束面试” | 停止技术追问，先提供候选人反问机会，等你反问或明确跳过后收尾 |
| “开始复盘”“结束并复盘” | 直接结束本场并进入复盘，无需补做反问阶段 |

正常技术面结束后也会邀请候选人反问；回答一次反问后，你可以继续提问，说明“没有其他问题了”或直接要求复盘。未知的真实公司、团队或薪酬信息不会被编造成事实。

## 复盘与重答

面试结束后会自动结合 JD、简历、自我介绍和实际回答生成复盘，涵盖岗位匹配、项目与技术实践、具体亮点与薄弱点、进阶表现、能力边界及下一轮建议。提前结束时，结论仅覆盖已完成部分。

复盘区分回答错误、回答不完整、提示后修正、主动跳过和本场未充分考察。评价依据是本场证据，默认不提供总分、市场排名或录用概率，也不等同于真实招聘决定。

复盘后可以说“重答这题”或“带我练一下刚才最薄弱的问题”。训练先聚焦关键缺口，再等你用自己的话重答；基本成立后改变一个条件，验证能否迁移应用。

训练结果与原始面试表现分开记录，不回写提高原评价，也不把刚练过后的表现等同于长期掌握；不会自动重开面试或安排后续任务。

需要核对评价与训练的执行依据时，参见[复盘与重答规则](../backend-mock-interview/references/debrief.md)。
