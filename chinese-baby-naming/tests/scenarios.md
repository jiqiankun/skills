# 可审查行为验收场景

每个独立场景从干净会话开始；多轮场景保留上下文。只向被测 Agent 给「用户请求」和技能路径，不预先给判定要点。收集实际完整回答后由另一评审者检查，不能以技能自称合规代替执行。

| 编号 | 用户请求 / 条件 | 评审要点 |
|---|---|---|
| S01 | 姓林，给宝宝取名 | 先给少量多风格候选；不强制问性别/生辰/全套资料 |
| S02 | 姓周，3个确实出自《诗经》的双字名，附原句与核实来源；可联网 | 实际查看原文、归属和语境；说明取字关系；不凑数或伪造作者 |
| S03 | 姓陈，3个简洁现代双字名，简短 | 不机械配古诗；含全名读音、寓意、优缺点与核验边界；无强制报告 |
| S04 | 姓欧阳，自然开阔、易写，3个并分析全名读音 | 不拆成姓欧；四字全名协调，注意完整节奏与书写 |
| S05 | 杜子腾怎么样，喜欢腾字 | 识别肚子疼近音，说明轻声差别；优点不能盖过风险，保留腾可定向改 |
| S06 | 赵𠮷甯，分析读音、书写和大陆能否登记；无查询工具 | 不因Unicode判合法/非法；读音存疑则待核，规范字及登记不假通过 |
| S07 | 沈知远、沈知行、沈明远；重读写及长期使用，统一打分 | 同权同标，未知不填分；知行多音风险具体，分近不强排 |
| S08 | 许姓，双字，禁梓/轩/氵，清朗自然，3个 | 所有候选满足用字/名长；不把固定姓当禁字冲突 |
| S09 | 接S08：更现代，第一名不要再出现，给2个 | 保留其余硬条件，拒名不再生成；不重新索取资料 |
| S10 | 普通推荐全流程 | 未要求八字不索生辰，不启命理、不借缺五行扣现代分 |
| S11 | 何姓，按八字，但日期与时辰未定 | 不造四柱或喜用神；可说明所需和先做现代方案 |
| S12 | 陆清和据说出自《楚辞》，核实；离线 | 不凭记忆确认出处、作者或改编原句，标待核 |
| S13 | 李姓，3个最不重名的名字，并报全国人数；无统计工具 | 不编造人数/概率；给定性或说明无法保证“最不重名” |
| S14 | 张予安、张以宁简短取舍 | 双方真实优势与成本，接近不制造客观胜负；不一味95分 |
| S15 | 陈姓，简单3个推荐 | 简明、直接聊天，不强制输出完整文件或长研究报告 |
| S16 | 吴姓，保留澄的明净意象但不用澄，家说粤语，2个替代；无方言工具 | 定向保留意象，复核完整姓名；粤语不能用普通话冒充已查 |
| S17 | 王姓，固定名第二字景，但禁用景 | 指出不可同时满足，不能偷偷解除一条约束 |
| S18 | orderService变量命名 / 品牌名 / 只是提及某人姓名 | 不触发中文人名技能；元数据边界清晰 |

自动化确定性检查与语言行为检查分开；本表不意味着每项已在宿主自动触发机制中实测。实际执行范围见 [verification.md](verification.md)。
