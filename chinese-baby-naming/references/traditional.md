# 可选传统姓名学

只有用户明确请求八字、五行、生肖、五格三才等对应模块才启用；只要求五格不索要出生时间。仅问「有文化内涵」不视为同意命理。

开头简短说明：这是传统文化视角，不是科学预测；不同规则体系可能给出不同判断。与现代姓名评价并排展示，保留现代分与现代排序，传统偏好可另给一列或单独序列，不混成总分。

## 信息与可靠计算

八字需要用户愿意提供的出生日期及历法、出生时间精度、出生地所需时区信息；地点只到城市或时区，不要住址。农历须确认闰月，日期未知不能推算。涉及历史夏令时、节气边界或跨日时辰须复核；不要把公历月份当月柱，也不要简单按立春前后猜整套四柱。

在现有工具确实支持、来源可说明时计算，并记录：

- 工具/库及版本、历法和节气来源；输入日期口径和时区。
- 年/月柱边界，日界采用子初还是零点，时柱规则；是否使用真太阳时及具体换算依据。
- 各已知柱的依据、未知范围，以及边界处的备选方案。

没有时辰不能虚构时柱；日期也缺失时不列八字。只有部分信息可可靠算出时，仅给明确的部分与限制，否则给文化解释与需要的信息，不捏造历法结果。本 Skill 未内置历法引擎，不能声称已计算。

喜用神不能由「五行缺什么就补什么」机械推出；区分计数、藏干、季节与流派解释。字的传统五行可来自部首、字义、音韵或数理等不同体系，须说明采用哪种及其出处，不将这些分类当作汉字的客观物理属性。

## 五格、三才与笔画

只有用户要求且采用的规则明确时计算。先说明采用康熙/现代笔画口径、简繁/异体映射、单姓/复姓及单名/双名的对应规则；不同体系有差异时不要混算。字典未收或异体映射存疑就将受影响格数标未知，不为了出结果改用另一笔画口径。

下面是常见五格体系的一组公式，仅在用户接受此体系时使用：设姓氏各字笔画为 S，名字各字笔画为 G，T 为全名笔画和。

| 格 | 本体系公式 |
|---|---|
| 天格 | 单姓 `S1+1`；复姓 `ΣS` |
| 人格 | `姓氏末字笔画 + 名字首字笔画` |
| 地格 | 单名 `G1+1`；双名 `ΣG` |
| 总格 | `T` |
| 外格 | `T-人格+单姓补1+单名补1`（相应情形各补一次） |

此表只覆盖单/复姓与单/双名的常见情况，更长结构不能直接外推。三才取天、人格、地格，再按声明的数理映射解释；吉凶表、数理五行映射如未有可靠来源，不输出吉凶结果。可以只给用户可复算的格数并说明解释待核。

生肖宜忌、偏旁忌根、地支联动等属于特定习俗；不能因某一流派认为不吉就淘汰现实优秀的姓名。不要声称偏旁或谐音会影响婚姻、疾病、财富、子女或寿命。禁止「必定富贵」「注定失败」等断语，也不要暗示更名能治病、改善成绩或改变命运。
