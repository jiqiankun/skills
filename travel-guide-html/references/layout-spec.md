# 页面与实现规范

## 信息架构

顺序为顶部旅行标题 → 吸顶导航 → 总览／Day 1…N／特产（适用时）／准备清单。默认总览，日期可直接定位；总览有每日入口、往返交通、预算、住宿与核验来源。

每日先显示主题、Dashboard、关键提醒和当晚／返程衔接，再显示时间轴与适用备用方案。景点详情使用一级原生 details/summary；不为主要内容增加嵌套折叠。来源可集中，重要的开放与预约限制必须在相关卡片直显。

| 直显 | 折叠或次级 |
|---|---|
| 时间、地点、价值摘要、交通与耗时、停留、关键门票／预约、最晚离开、当日重点提醒 | 景点详细顺序、内部路线、背景细节、避坑、少量附近推荐、按需摄影 |
| 正餐安排、排队替换条件、住宿／返程衔接 | 详细点法、区域比较、低频便民信息 |

可选内容缺失时删除对应元素；特产整页删除时同时移除导航。不显示空标签或“无内容”的折叠。模板只保留一个 Day 骨架，按实际天数复制并同步导航、标题 ID 和总览入口；不附带固定目的地示例。

## 视觉与移动端

- 使用模板中的浅色底、深色正文、柔和顶部渐变、细边界和轻阴影。主强调蓝，景点青绿／美食珊瑚／文化紫色／交通灰只做小面积分类，标签保留文字。
- 正文16px、行高约1.7，辅助文字不小于14px；不要把主要攻略缩成小字。标题自然换行，正文左对齐；不强求所有区块居中。
- 页面主体最大宽度1080px，窄屏正文单栏；宽屏详情和卡片可两列。Dashboard 用少量紧凑的指标组，避免在手机上占满多个屏幕。网格使用 minmax(0, 1fr)，跨全行用 grid-column: 1 / -1，避免隐式列。
- 360～430px 优先；卡片约16px内边距、12～16px间距。时间与类别一行可换行，长地点名称另起一行。长地址、链接与标签可断行，不以隐藏横向溢出掩盖内容裁切。
- 导航允许单行横向滚动，其他正文不横向滚动。链接和展开入口至少44px高，焦点可见；提供跳过导航入口。锚点定位留出吸顶导航高度，展开不设固定高度上限。
- 不用宽表格承载手机正文，不使用绝对定位徽章、大量渐变、无数据含义的图表或复杂动画。装饰与颜色不承担唯一的信息表达。
- 顶部建立目的地标题、旅行摘要和核心体验的清晰层级；正文使用节奏一致的留白、分隔和小面积类别色。总览先解释路线逻辑，再给每天入口；每日强调主题与关键时间，详情中放丰富的玩法。内容卡片避免每条信息再套一个小卡片。
- 有合适且可验证的真实目的地图片时，可加入一张封面或少量核心景点图，配标题／说明；不以无关图库图片冒充目的地，不要求每卡有图。设定宽高或宽高比、适当压缩，非首屏图片延迟加载，图片不可用时仍能完整阅读正文。
- 摄影仅在地点详情内作为次级段落，使用同一套细节样式，无额外主题配色和日级摄影界面；启用条件遵守主说明。

## 静态正文与渐进增强

- 从 assets/guide-template.html 改写，全部攻略直接存在于 HTML；不得将正文留空再依靠 JS 生成，也不维护重复的 OVERVIEW／DAYS 等运行时数据。
- 保留原生锚点导航及 details/summary。少量内联 JS 仅增强为单页显示，使用 hash 支持直达与前进后退；切页不重建正文、不丢失折叠状态，焦点与标题一起定位。
- HTML 初始不隐藏任何正文；JS 禁用、语法错误或增强失败时退回完整文档。不要用 noscript 中的一句提示替代攻略正文。
- 页面 ID 使用 overview、day-1…day-N、souvenirs、prep；导航指向真实 ID。页面内的其他锚点也使用唯一 ID，JS 可切入目标所在页。
- 文本按 HTML 文本节点转义，属性值按属性上下文转义；不要将检索文本直接当 HTML 或拼入脚本。来源链接只允许 http/https，内部导航只用本文件锚点；不接受 javascript: 或事件属性。内容无需嵌入 JS。
- head 保留 UTF-8、viewport；默认系统字体。核心 CSS、JS 与正文内联，保证交付单个可直接打开的 HTML；允许按需使用 HTTPS 在线图片和资料链接，不再要求离线或零网络依赖。
- 视觉资源优先有意义的 CSS、内联 SVG 或真实目的地图片，Emoji 适量。字体、库或其他外部服务只有明确收益时才引入；不使用地图或追踪器，不默认使用 CDN、自动播放媒体或实时 API。无需 Service Worker、缓存框架或本地服务器。
- 控制图片尺寸与加载成本，在线资源不可用时保留文字与空间稳定性。代码按样式、正文、导航增强分区，注释使用中文；复杂度应服务阅读与内容展示。

## 检查方法

主说明维护完成标准，这里只规定页面检查方法：

1. 用本地 file:// 打开文件；若使用在线资源，核对 URL、来源、加载表现与失败时的替代显示。导航和攻略正文不依赖远程接口返回后才出现。
2. 逐页点击导航，测试前进后退、直接带某日锚点打开、展开／收起、键盘 Enter／空格和焦点；可选模块移除后仍可导航。
3. 在360、390、430px与桌面宽度检查全部展开、长标题／链接和文字放大；正文无横向溢出或裁切，导航定位后标题可见。
4. 禁用 JS 重新加载，所有页面内容仍在，锚点和原生折叠可用；浏览器控制台不应有正常使用错误。
5. 维护模板时运行 scripts/check-template.cjs；使用现有 Node、Playwright 与可用浏览器，不将开发测试依赖放入最终 HTML。命令为 node scripts/check-template.cjs，GUIDE_BROWSER 可指定本机 Chromium 浏览器路径；GUIDE_ENGINE 可选 webkit（需已有对应浏览器）。未实测的平台如实记录。
