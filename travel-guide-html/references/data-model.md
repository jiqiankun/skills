# 内容与字段约定

这是规划和展示的内容契约，不是 JSON Schema。最终正文直接写入 HTML；下列名称用于组织信息，不要求创建 JS 变量、数据文件或每条信息一个字段。未知与不适用不同：关键未知项写状态及影响，不适用项直接省略。

## 总览与准备

| 区域 | 内容 |
|---|---|
| 旅行信息 | 标题、目的地、日期（含年份，未定则说明）、天数、人数或计价口径、关键偏好与假设 |
| 整体路线 | 城市／区域与住宿夜数、往返交通；用简短说明解释路线与住宿选择，突出此行最值得体验的内容 |
| 每日核心 | 从最终时间轴提取主题、核心安排和强度，链接到对应日；不独立维护另一套计划 |
| 预算 | 总额或范围、主要分项、人数／每间每晚／单程往返、包含与不包含的费用；与每日口径相同 |
| 预约提醒 | 仅列会影响执行的项目及截止条件；具体行动放准备清单 |
| 信息来源 | 关键结论、来源名称与链接、核验日期、已确认／估算／待确认状态；正文直接说明结论，不让用户逐个打开链接才知道限制 |
| 准备清单 | 按需分为预订、证件、装备、行李与出发前复核；每项写行动和适用时间，非预订事项不套“提前订票”句式 |

## 每日内容

- **标题与日期**：当日主题及核心游览链；日期未定时不编写星期。
- **Dashboard**：核心景点数、建议出发与结束时间、预计步行范围和强度、主要交通方式与总耗时、预算或主要花费、重点提醒。天气与穿衣按核验状态合并，海拔只在相关时展示。信息分组，不把所有内容拆成徽章。
- **当晚安排**：住宿区域和必要地理衔接；返程日改为去站点、取行李与最晚离开时间，不渲染空住宿。
- **时间轴**：活动开始—结束／停留时长、地点与类型、值得去的理由；地点变化时有前站至本站的交通方式、门到门耗时与入口。必要时注明等待与休息。交通节点明确“出发”“到达”“发车”或“起飞”。
- **备用方案**：触发条件、删减／替换动作、耗时变化、接回主线的位置与硬截止。覆盖全程适用的雨雪、高温严寒、关闭／预约失败、排队、延误／起晚、提前完成及体力不足；相同处理合并，不每天机械列全套。

## 核心景点

每个核心景点用简洁段落回答：

1. 为什么值得去、适合什么兴趣、建议停留多久。
2. 入口 → 核心看点 → 出口的游览顺序；重点讲看什么、怎么看，而非只列名字。根据目的地补充有依据的历史文化背景、自然或季节特色，帮助用户理解眼前的景观，不为每个点强加百科介绍。
3. 有价值的易错过细节，以及时间不足可跳过的区域；说明不同兴趣、体力和剩余时间怎样取舍。
4. 最佳到达时段及理由；门票单位、预约、开放／闭馆、最晚入场等关键限制。限制直显，详细说明可折叠。
5. 结束后怎样接下一站；需要时说明厕所、寄存、无障碍、停车和休息点。

大型景区将内部步行、接驳和优先级写清，不重复外部交通或套固定景区名单。普通交通／入住节点只需时间、地点、衔接和提醒，不套景点详情。可选摄影内容的位置见布局规范，启用与规划边界以 SKILL.md 为准。

## 美食

优先“当地特色吃什么”，再选路线上的区域或店铺；嵌入早餐、午餐、晚餐，小吃和夜宵按需追加。

- 说明特色／推荐菜、人均价格区间、适用人数点法、口味与已知忌口。
- 区分“顺路吃”和“值得专程”；后者解释额外交通与时间成本，不能挤掉硬约束。
- 热门店给排队上限建议及附近替代，写明何时切换，不声称精确排队时间。
- 具体店铺注明可找到的分店／地址及营业核验状态；无需专门找店的早餐、小馆可按区域推荐，普通餐次允许简写。

## 住宿

仅对需要住宿的行程提供。优先一个区域及有实际取舍的备选，必要时2～3个，不凑数。

每个区域写适用夜晚、每间每晚参考价格、与前日终点／次日首站／返程节点的关系、减少哪些折返，以及早餐夜宵、交通、停车、行李方面的关键取舍。具体酒店按日期、预算、房型需求和可核验信息推荐；已有酒店无需重新推荐。区域理由总览写一次，每日只写当晚选择与衔接。

## 附近与顺路项

允许没有。只保留真正短距离可达或顺路的少量选择，标“主计划之外”；说明插入点、到达／绕行耗时、游玩时长和接回主线方式。按剩余30分钟、1小时或2小时选择适用档位，不要求每档凑一个。不将附近项计入主行程时间、景点数或预算；可选费用另标。

## 伴手礼与特产

按目的地和用户需求推荐；无合适内容可省略整个页面和导航。每项写：

- 买什么、参考价及单位、是否值得买。
- 推荐购买区域或已核验店铺；为什么在这里买（价格、品质、方便等），不只重复商品优点。
- 建议在哪天、返程前哪个空档买，避免增加折返。
- 携带体积、易碎、液体、冷藏或运输限制等适用信息。
- 实际有依据的溢价／踩坑提醒和可不买的内容；不编造负面评价或精确地址。

## 一致性

总览、每日和准备清单都来自同一份已核对计划；允许摘要重复，不分别维护冲突的时间和价格。所有时间和金额带明确口径，范围不能在汇总时偷偷变为确定值。已确认限制与估算值分开；不适用模块不输出空标签、空折叠或占位符。
